# ADA_LAB

This repository contains lab programs and activities for the course **Analysis & Design of Algorithms (ADA)**.  
It covers fundamental algorithmic paradigms including searching, sorting, greedy methods, and graph algorithms.

---

## Program List

### Searching Algorithms
1. **Linear Search**
   - Search for an element by scanning the list sequentially.
   - Time Complexity: O(n)

2. **Binary Search**
   - Efficient search on a sorted list using divide and conquer.
   - Time Complexity: O(log n)

---

### String Matching
3. **Naïve String Matching Algorithm**
   - Basic pattern matching by checking all alignments.
   - Time Complexity: O(n * m)

---

### Sorting Algorithms
4. **Bubble Sort**
   - Repeatedly swaps adjacent elements if they are in the wrong order.
   - Time Complexity: O(n²)

5. **Selection Sort**
   - Selects the minimum element and places it at the correct position.
   - Time Complexity: O(n²)

6. **Insertion Sort**
   - Builds a sorted list one element at a time.
   - Time Complexity: O(n²)

7. **Quick Sort**
   - Divide-and-conquer sorting using pivot partitioning.
   - Average Time Complexity: O(n log n)

---

### Graph Algorithms
8. **Prim’s Algorithm**
   - Finds Minimum Spanning Tree (MST) using greedy approach.
   - Time Complexity: O(V²) / O(E log V)

9. **Floyd’s Algorithm (Floyd-Warshall)**
   - Computes shortest paths between all pairs of vertices.
   - Time Complexity: O(V³)

10. **Bellman-Ford Algorithm**
   - Finds shortest path from a source vertex (handles negative weights).
   - Time Complexity: O(V * E)

11. **Warshall’s Algorithm**
   - Computes transitive closure of a directed graph.
   - Time Complexity: O(V³)

---

### Greedy Algorithms
12. **Fractional Knapsack Problem**
   - Maximizes value with fractional item selection.
   - Time Complexity: O(n log n)

---

## Objective
To understand and implement core algorithmic techniques:
- Brute Force
- Divide & Conquer
- Greedy
- Dynamic Programming concepts (intro level via Floyd/Bellman)
